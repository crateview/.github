## Explore your registry

Crateview makes container registries easier to browse. Explore repositories and tags, inspect multi-platform images, and view manifests, image configuration, layers and OCI referrers through a clean web interface.

- **Registry-native:** built on the Registry HTTP API V2, Docker and OCI image formats.
- **Self-hosted:** connect to an existing registry or run the included Docker Compose stack.
- **Adaptable:** configurable branding, light and dark themes, and English and German interfaces.
- **Practical:** copy commands for Docker, Podman, Skopeo and ORAS; use anonymous access or registry Basic Auth.
